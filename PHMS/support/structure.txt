ROOT LEVEL FILES:
─────────────────
app.py
  - Creates Flask app instance
  - Initializes database
  - Registers all routes
  - Entry point: python app.py

  - Flask configuration
  - App secrets & constants

  - Calls controller functions

reports.py
  - Report generation utilities
  - Data aggregation functions
  - Export/PDF generation (if implemented)

requirements.txt
  - All Python package dependencies
  - Version specifications for reproducibility

================================================================================
                           ARCHITECTURE FLOW
================================================================================

REQUEST FLOW:
1. Browser sends HTTP request
2. routes.py catches the route
3. routes.py calls controller function
4. controller imports models & config
5. controller queries database via models
6. controller returns response/renders template
7. Browser receives & displays response

EXAMPLE: GET /health
├── routes.py: @app.route('/health')
├── Calls: health_controller.health_page()
├── Controller: queries HealthData from models
├── Database: fetches user's health entries
├── Controller: checks for alerts based on data
├── Returns: render_template('health.html', entries=all_entries)
└── Browser: displays health tracking page

EXAMPLE: POST /add_health
├── routes.py: @app.route('/add_health', methods=['POST'])
├── Calls: health_controller.add_health()
├── Controller: extracts JSON data from request
├── Controller: creates new HealthData object
├── Database: saves entry and checks alert conditions
├── Logic: generates Alert if thresholds exceeded
├── Returns: JSON response with status
└── Browser: updates UI with new entry


DATABASE RELATIONSHIPS:
User (1) ──→ (many) HealthData
User (1) ──→ (many) Medication ←─ (many) Medicine (master)
User (1) ──→ (many) Alert
Medication (1) ──→ (many) MedicationLog


================================================================================
                         DEVELOPMENT GUIDELINES
================================================================================

✓ Don't edit:  venv/, __pycache__, instance/
✓ Do edit:     Source files in root, controllers/, models/, templates/, static/
✓ Keep clean:  No hardcoded values, use config.py
✓ DRY:         Reuse functions from controllers
✓ Comments:    Add docstrings to functions
✓ Structure:   One model per file, one controller per feature

NEW FEATURE CHECKLIST:
1. Add model in models/ folder
2. Add export in models/__init__.py
3. Add controller in controllers/ folder
4. Add route in routes.py
5. Add template in templates/ folder
6. Add styles in static/style/ folder

ROUTE CONVENTIONS:
  - GET routes: display pages or retrieve data
  - POST routes: create or submit data
  - PUT routes: update existing resources
  - DELETE routes: remove resources
  - Use snake_case for Python functions
  - Use camelCase for HTML form fields
  - Return JSON for AJAX requests
  - Return HTML for page navigation
