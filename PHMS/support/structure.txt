MACHINE LEARNING WORKFLOW:
  1. Collect health data from user input
  2. Retrieve user's BMI from User model
  3. Call ml_model.predict_health_risk() with 7 features:
     [bmi, heart_rate, temperature, steps, sleep_hours, blood_pressure, sugar]
  4. Call utils.health_score.calculate_health_score() for rule-based score
  5. Store both predictions in HealthData table
  6. Generate alerts for High Risk predictions
  7. Display results to user with color-coded indicators

  - Navigate to ml/training_scripts/

  - New model artifacts saved to ml/trained_models/
  - Update ml/ml_model.py to load new version
  - Update ml/README.md with new performance metrics
