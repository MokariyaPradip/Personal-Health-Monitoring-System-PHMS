ROUTING AND REQUEST FLOW
================================================================================
1) app.py creates app via create_app()
2) routes.py calls register_feature_routes(app)
3) feature_routes/*.py defines URL rules and delegates to controllers
4) controllers/*.py handles request/response shape and delegates to services
5) services/*.py implements domain logic and delegates persistence to repositories
6) repositories/*.py encapsulates ORM query blocks

DEVELOPMENT GUIDELINES
================================================================================
- Do not edit generated/runtime folders: venv/, instance/, __pycache__/
- Add new HTTP endpoints in feature_routes first, not in routes.py directly
- Keep controllers thin; business logic belongs in services
- Keep direct ORM queries inside repositories
- Keep setup and runtime instructions in root instructions.txt
  and mirror that file into support/instructions.txt when updated
