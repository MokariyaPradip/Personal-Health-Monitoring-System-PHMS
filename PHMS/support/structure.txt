MACHINE LEARNING WORKFLOW:
  1. Collect health data from user input
  2. Retrieve user's BMI from User model
  3. Call ml_model.predict_health_risk() with 7 features:
     [bmi, heart_rate, temperature, steps, sleep_hours, blood_pressure, sugar]
  4. Call utils.health_score.calculate_health_score() for rule-based score
  5. Store both predictions in HealthData table
  6. Generate alerts for High Risk predictions
  7. Display results to user with color-coded indicators

MODEL RETRAINING:
  - Navigate to ml/training_scripts/
  - Run: python train_model_v5.py (or next version)
  - New model artifacts saved to ml/trained_models/
  - Update ml/ml_model.py to load new version
  - Update ml/README.md with new performance metrics
  - Test predictions before deploying to production

SECURITY FEATURES:
  ✓ Flask-Login: Session-based authentication
  ✓ CSRF Protection: All POST/PUT/DELETE routes protected
  ✓ Password Reset: Token-based with 30-minute expiry
  ✓ Strong Passwords: Minimum 8 characters enforced
  ✓ Secure Cookies: HttpOnly, SameSite, Secure flags
  ✓ SQL Injection: Prevented by SQLAlchemy ORM
  ✓ Environment Variables: Secrets stored in .env file
  ✓ Token Signing: URLSafeTimedSerializer for password reset

DATABASE OPERATIONS:
  - Database type: SQLite (phms.db)
  - Location: instance/ folder (auto-created)
  - Migrations: Alembic/Flask-Migrate for schema changes
  - Commands:
    * flask db init (one-time setup)
    * flask db migrate -m "description" (create migration)
    * flask db upgrade (apply migrations)
    * flask db downgrade (rollback)

PERFORMANCE CONSIDERATIONS:
  - ML model loads once on startup (37MB RandomForest v5)
  - Predictions are fast (<10ms per request)
  - Database indexes on foreign keys and email fields
  - Pagination for health data and medication lists
  - Health score calculation is lightweight (pure Python)
