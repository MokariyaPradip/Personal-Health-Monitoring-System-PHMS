OVERVIEW
================================================================================
PHMS implements a comprehensive health prediction system with THREE parallel 
assessment paths to provide robust, explainable health risk evaluation:

1. Rule-Based Scoring (Explainable, Deterministic)
2. ML Regression Model (Continuous Health Score Prediction)
3. ML Classification Model (Categorical Risk Label Prediction)

This hybrid approach combines domain knowledge, regression analysis, and 
classification models for clinical decision support.


PROCESSING FLOW (Health Data Entry)
================================================================================

┌─────────────────────────────────────────────────────────────────────────┐
│ 1. DATA INPUT PHASE (Health Controller - health_controller.py)         │
└─────────────────────────────────────────────────────────────────────────┘
   User submits health data via Flask form at /health/add endpoint
   
   Input Parameters:
   - heart_rate (bpm)
   - temperature (°C)
   - steps (daily count)
   - sleep_hours (hours)
   - blood_pressure_systolic (mmHg)
   - blood_pressure_diastolic (mmHg)
   - sugar_level (mg/dL)
   - BMI (calculated from user profile: weight / height²)
   
   Validation: Flask-WTF form validation for ranges and data types


┌─────────────────────────────────────────────────────────────────────────┐
│ 2. TRIPLE ASSESSMENT PHASE (Parallel Processing)                       │
└─────────────────────────────────────────────────────────────────────────┘

   ┌────────────────────────────────────────────────────────────────┐
   │ PATH A: RULE-BASED SCORING (utils/health_score.py)            │
   └────────────────────────────────────────────────────────────────┘
   Function: calculate_health_score()
   
   Threshold-Based Penalty System:
   ┌──────────────────┬───────────────────┬──────────────────────┐
   │ Parameter        │ Healthy Range     │ Penalty Structure    │
   ├──────────────────┼───────────────────┼──────────────────────┤
   │ BMI              │ 18.5 - 24.9       │ Overweight: -5       │
   │                  │                   │ Obese: -15, -25      │
   │                  │                   │ Underweight: -10     │
   ├──────────────────┼───────────────────┼──────────────────────┤
   │ Heart Rate       │ 60 - 100 bpm      │ Outside: -10 to -20  │
   ├──────────────────┼───────────────────┼──────────────────────┤
   │ Blood Pressure   │ 90-120 / 60-80    │ Elevated: -20, -30   │
   │ (Systolic/Dias.) │                   │ Critical: -40        │
   ├──────────────────┼───────────────────┼──────────────────────┤
   │ Sugar Level      │ < 100 mg/dL       │ Prediabetes: -15     │
   │                  │                   │ Diabetes: -25        │
   ├──────────────────┼───────────────────┼──────────────────────┤
   │ Sleep Hours      │ ≥ 7 hours         │ < 7: -15             │
   │                  │                   │ < 5: -25             │
   ├──────────────────┼───────────────────┼──────────────────────┤
   │ Steps            │ ≥ 7000 steps      │ < 7000: -10          │
   │                  │                   │ < 3000: -15          │
   ├──────────────────┼───────────────────┼──────────────────────┤
   │ Temperature      │ ≤ 37.8°C          │ Fever: -10 to -15    │
   └──────────────────┴───────────────────┴──────────────────────┘
   
   Computation:
   - Start: 100 points (perfect health)
   - Apply: Deduct penalties for out-of-range values
   - Result: health_score (0-100)
   
   Output: Stored in health_data.health_score column


   ┌────────────────────────────────────────────────────────────────┐
   │ PATH B: ML REGRESSION MODEL (ml/ml_model.py)                   │
   └────────────────────────────────────────────────────────────────┘
   Model: ElasticNet Regression v4
   File: ml/trained_models/phms_regression_v6.pkl
   
   Purpose: Predict continuous health score (0-100) using ML
   
   Feature Engineering:
   - Input Order: [BMI, BP_Systolic, BP_Diastolic, Sugar, Heart_Rate, 
                   Sleep_Hours, Steps, Temperature]
   - Preprocessing: StandardScaler normalization (fitted during training)
   
   Model Details:
   - Algorithm: ElasticNet (L1 + L2 regularization)
   - Alpha: 0.01 (regularization strength)
   - Training: 25,884 records (4 combined datasets)
   - Performance: R² = 0.89, MAE = 4.32
   
   Prediction Flow:
   1. Load model: phms_regression_v6.pkl
   2. Prepare features: [bmi, bp_sys, bp_dia, sugar, hr, sleep, steps, temp]
   3. Scale features: StandardScaler transform
   4. Predict: model.predict(scaled_features)
   5. Post-process: Clip to range [0, 100]
   
   Output: Stored in health_data.ml_regression_health_score column


   ┌────────────────────────────────────────────────────────────────┐
   │ PATH C: ML CLASSIFICATION MODEL (ml/ml_model.py)               │
   └────────────────────────────────────────────────────────────────┘
   Model: RandomForest Classifier v6
   File: ml/trained_models/phms_classifier_v6.pkl
   Encoder: ml/trained_models/label_encoder_v6.pkl
   
   Purpose: Classify health risk into discrete categories
   
   Feature Engineering:
   - Input Order: [BMI, BP_Systolic, BP_Diastolic, Sugar, Heart_Rate, 
                   Sleep_Hours, Steps, Temperature]
   - Same preprocessing as regression model
   
   Model Details:
   - Algorithm: RandomForest (ensemble of 100 decision trees)
   - Training: 25,884 records (4 combined datasets)
   - Performance: Accuracy = 96.8%, F1-Score = 0.967
   - Class Distribution:
     * Low Risk (Healthy): 40%
     * Medium Risk (Moderate): 35%
     * High Risk: 20%
     * Critical Risk: 5%
   
   Feature Importance (Top 5):
   ┌──────────────────────┬────────────────┐
   │ Feature              │ Importance %   │
   ├──────────────────────┼────────────────┤
   │ Sugar Level          │ 26.3%          │
   │ BMI                  │ 21.7%          │
   │ Blood Pressure (Sys.)│ 18.5%          │
   │ Heart Rate           │ 13.8%          │
   │ Sleep Hours          │ 9.2%           │
   └──────────────────────┴────────────────┘
   
   Prediction Flow:
   1. Load model: phms_classifier_v6.pkl
   2. Load encoder: label_encoder_v6.pkl
   3. Prepare features: [bmi, bp_sys, bp_dia, sugar, hr, sleep, steps, temp]
   4. Scale features: StandardScaler transform
   5. Predict: model.predict(scaled_features)
   6. Decode: label_encoder.inverse_transform(prediction)
   7. Map to standard labels: Low/Medium/High/Critical → Healthy/Moderate/HighRisk
   
   Risk Categories:
   - Healthy (Low): All vitals in healthy range
   - Moderate (Medium): 1-2 risk factors present
   - HighRisk (High/Critical): 3+ risk factors or critical condition
   
   Output: Stored in health_data.ml_classifier_risk_label column

   - min_samples_leaf: 4

API INTEGRATION (ML Model Interface)
================================================================================
File: ml/ml_model.py

Function: load_ml_models()
- Loads both classifier and regression models at app startup
- Caches in memory for fast predictions
- Handles FileNotFoundError gracefully

Function: predict_health(data_dict)
- Input: Dictionary with 8 features
- Output: Tuple (ml_regression_score, ml_classifier_label)
- Error handling: Returns (None, None) if prediction fails

Usage in Controller:
```python
from ml.ml_model import predict_health

# Prepare features
data = {
    'bmi': user.bmi,
    'blood_pressure_systolic': bp_sys,
    'blood_pressure_diastolic': bp_dia,
    'sugar_level': sugar,
    'heart_rate': hr,
    'sleep_hours': sleep,
    'steps': steps,
    'temperature': temp
}

# Get predictions
ml_regression_score, ml_classifier_label = predict_health(data)
```
